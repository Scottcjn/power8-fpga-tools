# Contributing to POWER8 FPGA Tools

FPGA programming tools ported to IBM POWER8 (ppc64le).

## Development Setup

```bash
git clone https://github.com/MingYu5/power8-fpga-tools.git
cd power8-fpga-tools
```

## Supported Systems

- IBM POWER8 (ppc64le)
- Xilinx FPGA tools

## Contributing

1. Fork the repo
2. Create a feature branch
3. Test on real hardware
4. Open PR against `Scottcjn/power8-fpga-tools:main`

Questions? Open an issue!
